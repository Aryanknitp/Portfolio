## ⚙️ Performance Optimization Tactics

To ensure a seamless experience across all devices, the following optimizations were implemented:
* **Asset Compression:** All 3D models were converted to `.glb` format and compressed using Draco compression.
* **Texture Baking:** Lighting and shadows were baked directly onto textures in Blender to drastically reduce real-time GPU calculation.
* **Lazy Loading:** 3D canvases and heavy components are conditionally loaded only when needed.
* **Responsive Rendering:** Pixel ratio and shadow maps dynamically scale down on lower-end mobile devices.
* **Attractive Video Introduction:** Introductory Video that give a point of view about me.

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### 📋 Prerequisites
Make sure you have Node.js and npm/yarn installed on your machine.

### 🔧 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

Open `http://localhost:5174` (or the port specified in your terminal) in your browser to view the site.
